# Valet Stand

A buildable clothes stand for **The Parasites**: a woven form of twigs and vine, propped up with stones. Put your clothes on it and they show on the stand in their own colour and wear. Press **Undress** to put everything you wear on the stand, and **Dress** to put it all back on.

This is a fan-made mod. It is not made or endorsed by the game's developer.

## Download

Get the mod from its Nexus Mods page or this repository's Releases. There are two files:

- **Valet Stand with UE4SS**: for players who don't have UE4SS yet. One zip, nothing else to install.
- **Valet Stand**: for players who already use UE4SS for other mods.

Extract the zip into the game's main folder, the one that contains the `TheParasites` folder, and let it merge. Each zip has an `INSTALL.txt` with the details.

## Requirements

- The Parasites, game version **0.1.6.0.2.5**. On any other version the script stops itself and logs one line.
- [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS), tested with v3.0.1 experimental build 1218 (included in the "with UE4SS" zip). UE4SS v4.0.0 is not tested yet.

When the game gets its own mod support, Valet Stand will move over to it.

## What is in this repository

Everything that makes up the mod, and nothing from the game.

| Folder | Contents |
|---|---|
| `Scripts/` | the mod's Lua, run by UE4SS: notebook entry, garments on the stand, Undress and Dress, version check, and `lang.lua` with the mod's text in the game's 22 languages |
| `shared/` | `game_version.lua`, the game version check shared between mods |
| `model/` | `ValetStand.blend`: the stand's five woven parts (Blender 5.2). `layout.json`: where every part sits, including the game's sticks and stones (by name) |
| `textures/` | vine, leaf, notebook picture and button icons |
| `unreal/` | `valetstand_assets.py`: builds the stand's Blueprints, materials and textures in the Unreal Editor |
| `INSTALL*.txt` | the install notes shipped in each zip |

The sticks and stones of the stand are the game's own meshes, referenced by name and not included. The game's assets are not part of this repository or its licence.

Building the pak needs the game's Unreal Engine 5.7 project, which is not included. The Lua comments refer to file paths in the original development setup.

## Translations

The stand's name, slot hints and button tooltips follow the game's language, in all 22 languages the game ships. They live in `Scripts/lang.lua`, one row per language. They were translated by AI, using the game's own words where those are right, and most have not been checked by a native speaker: corrections are welcome as issues or pull requests. In Thai, the two button tooltips stay English, because the engine's default tooltip font has no Thai letters.
